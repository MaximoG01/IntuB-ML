The question

With the data collected before induction (Mallampati, BMI, age, sex), can we predict Cormack 3–4 in obese patients? And does a model trained on another population work here too?

The data

{{ td.n }} obese adults (BMI 30–50) in elective surgery, from a randomized trial comparing the Macintosh blade with the Pentax AWS video laryngoscope. Cormack 3–4: {{ td.events }} patients ({{ "%.0f"|format(td.prevalence * 100) }}%).

Watch the coding: the dataset documentation says "1 = good = Cormack 3 or 4", which contradicts itself. Read literally it would give 82% Cormack 3–4. Checking against the other outcomes (ease, time, first-attempt success) shows that 0 = poor view. Always check the coding on the data, not only in the documentation.

The protocol, written first

Predictors, primary model (penalized logistic regression), metrics and threshold were fixed before looking at the results (SPEC §10). That way nobody can "pick the winner" afterwards.

What it would mean in the app

The penalized model shrank the weights almost to zero and gives almost everyone a risk close to {{ "%.0f"|format(td.prevalence * 100) }}%, above the 15% threshold. In practice it says: in an obese patient, always prepare plan B. This is consistent with the decision curve ("always prepare" beats "never" when the frequency exceeds the threshold), but it is not a model that helps tell patients apart.

Why a negative result matters

  • It shows that the limit is the data (few events, a single airway examination), not the algorithm.
  • It says what to collect: all the El-Ganzouri items, Cormack with a Macintosh blade, hundreds of events.
  • It demonstrates the method on real data: protocol written first, same folds for everyone, calibration, optimism, bias.
