The smallest possible model

A logistic regression with a single predictor, {{ pred }} (standardized: 0 = mean value, 1 = one standard deviation more), has two parameters:

risk = 1 / (1 + e−(b0 + b1 × {{ pred }}))

  • b0 (intercept): sets the risk of a patient with the mean value;
  • b1 (slope): how much the risk changes for each standard deviation of the predictor.

Training the model means finding the two numbers that make the error (log-loss) smallest: how "surprised" the model is, on average, by the true outcomes. With only two parameters the error can be computed for every pair (b0, b1) and drawn as a map: the error surface, computed here on {{ gd.n if gd and gd.n else "" }} real patients{% if teaching %} ({{ teaching.source }}){% endif %}.

What you see

  • At each step the model computes the direction in which the error falls fastest (the gradient) and moves a short way in that direction.
  • The first steps are long (the surface is steep), then they shorten near the bottom of the valley.
  • The bottom is at b0 ≈ {{ "%.2f"|format(gd.path[-1].b0) }}: 1/(1+e{{ "%.2f"|format(-gd.path[-1].b0) }}) ≈ {{ "%.0f"|format(100 / (1 + (-gd.path[-1].b0)|exp)) }}%, roughly the frequency of Cormack 3–4 in the dataset ({{ "%.0f"|format(gd.prevalence * 100) }}%).
    • {% if gd.path[-1].b1|abs < 0.25 %}
  • And b1 ≈ {{ "%.2f"|format(gd.path[-1].b1) }}: the valley is almost flat along b1. Changing the weight of {{ pred }} barely changes the error: in these patients the predictor hardly separates the difficult cases.
    • {% else %}
  • And b1 ≈ {{ "%.2f"|format(gd.path[-1].b1) }}: the bottom of the valley is far from b1 = 0. Removing the predictor (b1 = 0) would raise the error: {{ pred }} carries information about the difficult cases (in the obese-patient study, by contrast, the valley was flat along b1).
    • {% endif %}
  • The shape of the surface already tells how informative a predictor is.

A neural network does the same with hundreds of parameters: the surface can no longer be drawn, but the idea is the same. The new risk is that, with many parameters and few patients, the bottom of the valley corresponds to "learning by heart": that is overfitting.
